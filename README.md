# 扫描件去黑边

清除扫描图片中的黑边、黑角、阴影条带和页边噪点，**保持原图尺寸与方向不变**，被清除的区域用周围纸张纹理修补，不留色块和分界线。

思路参考：
https://blog.gtwang.org/programming/python-opencv-auto-crop-and-rotate-scanned-image-tutorial/
https://blog.csdn.net/gitblog_00476/article/details/153671634

## 用法

```bash
uv run python pic.py 图片路径      # 处理单张
uv run python pic.py 图片目录/     # 处理目录下所有图片（不递归）
```

结果输出到 `output/`，文件名与原图相同。可选参数：`-t` 黑边灰度阈值（默认 80），`-m` 黑边向外多扩的像素（默认 4）。

## 处理思路

**先找出“不该出现在纸上的东西”，把它们标记出来，再根据周围的纸张把这些地方“补”回干净的样子。** 整个过程不裁剪、不旋转，所以图片尺寸和方向都不会变。

扫描件上常见的“脏东西”有四类，各用一种办法找：

0. **大面积的浅色彩色噪点（复印机的粉色墨粉斑、扫描仪的彩色竖条纹）**
   - 怎么找：不写死颜色，而是看每个像素“和纸张底色相比带多少颜色”（Lab 色度）。把浅淡的彩色像素按密度连成区域，**铺满大片、或贯穿页面一大段**的才算噪点，再取这些区域的主色相，只清这个色相附近的颜色，替换成纸张底色。
   - 怎么保护：颜色浓的（红头、红线、印章笔画）和颜色深的（哪怕本身是粉色，如粉色复印件上的字）连同紧贴的边缘都不动；彩色照片这种“大片但浓色多”的区域不动；不贴边、大致成圆的区域视为印章，整个保留，所以浅粉色的印章也不会被当成噪点。
   - 墨粉斑里偶尔有几颗颜色较深的小点，若很小且周围没有字和线，也一并清掉；挨着文字的标点不受影响。


**先保护骑缝章**：骑缝章压在页边、被图片边缘截断，颜色又常常很浅，最容易被下面的黑边、贴边笔迹步骤当成“脏东西”清掉。所以在清除之前先把它圈出来，之后所有步骤都不碰这块区域（修补时也不从章上取色，避免抹出一圈红晕）。用两条线索，任一条命中即保护：
   - 颜色（彩色扫描）：贴着图片边缘、有一定厚度和面积的带色块。黑边、直线旁扫描产生的 1~3 像素彩边太细，不算。
   - 残缺圆弧（黑白扫描）：在每条边的贴边条带里，对线状墨迹做 RANSAC 圆拟合，要求半径符合公章尺寸、圆被图片边缘截断、图内露出的圆弧够长且大部分被**连续**的墨迹覆盖、圆弧内外两侧都是空白（是一条孤立的线）。拟合前先去掉表格线、黑边带等长直线，免得直线和圆相切时冒充圆弧。命中后整个圆内都保护。
   - 章上若正好压着一段黑边，按章两侧的黑边厚度推算，只清掉紧贴边缘的那一条黑带。
   - 保护区只在原图上检测一次，之后随图像一起旋转、纠偏；纠偏时骑缝章被转出画布的几个像素不会触发扩展画布。

1. **黑边、黑角（贴着图片边缘的大块黑色）**
   - 怎么找：把足够黑的像素圈出来，只留下“和图片边缘连在一起”的那些。纸上的字再黑也不会连到图片边缘，（todo liang 但是要考虑边缘上真正的档案字体）。
   - 怎么扩：黑边旁边通常还有一圈发灰的过渡和过曝的白带，所以向外多扩一圈，一起处理掉，免得留下一条“边”。

2. **页边的“边框带”（颜色和纸不一样的窄条）**
   - 怎么找：有些扫描件边缘没有黑边，只有一条偏白、偏灰的窄带，或一条很淡的细线。办法是从图片边缘往里，一排一排地看像素的“典型亮度”（取中位数，不怕个别噪点），一直看到亮度和纸张正常亮度一致为止，这一段就是边框带。
   - 怎么保护：边框带常是扫描造成的亮度渐变，可能有几十像素宽，压在里面的手写字（如页边的档案编号）不随边框带一起抹掉；细暗线、长横线、贴着图片边缘被截断的残迹照常清除。

3. **页边的小黑点和杂笔迹（正文以外的噪点）**
   - 怎么找：先把一行行的字“糊”成条，圈出正文区域。正文区域之外，如果有小团块的黑点，并且周围一片空白（没有别的字），就当噪点；紧贴图片边缘被截断的笔迹，多半是别的页透过来的，也一并去掉。
     - 页边常有一串挨在一起的墨点：只有字、线这样的“大墨迹”才说明附近是正文，成片的小墨点不能互相证明是文字（带颜色的除外，见下）。
     - 墨点外常有一圈浅灰的晕，只清深色核心会留下灰影：清除时连同浅色晕一起去掉；没有深色核心的浅灰小点，只要小、成团、附近没有大墨迹，也清掉。
     - “被截断”要真的碰到图片边缘或第 1 步清掉的黑边；离边缘还有一段空白、字大小、笔画构成的块是页边完整的手写字（如页码、档案编号），保留。
   - 怎么保护：成串的文字、细长的手写笔画（比如页角手写的“1”）不会被当成噪点，因为文字周围总有别的字，笔画也不是小团块的形状。浅色印章、彩色笔迹的碎笔画（周围的浅色墨迹多半带颜色）不按“成片小墨点”放宽，也不向外扩清浅色晕；页边一圈的浅色笔画（装订孔轮廓等）不当浅灰小点清除。紧挨着字、落在同一行中段的短横和小点是标点（如页码“- 2 -”两侧的短横），保留。

**补回干净的样子**：标记出来的区域，用图像修补算法（Telea）从四周的纸张“长”出来填满，边缘做了柔和过渡，所以看不出补过的痕迹，也不会出现一块纯白色块。靠近标记区的文字笔画会先被“忽略”着参与计算，补完再原样放回，这样笔画的黑色不会晕染到补过的地方。

## 已知局限

- 假设页边最外约 4% 内没有真实内容；页边 3% 以内、版心之外的内容，若被图片边缘或黑边截断、或比字小、或是实心墨团，会被当作残留清除（完整的手写字保留）。
- 不接触图片边缘的黑色区域不会被识别为黑边。
- 黑白扫描的骑缝章若外圈圆弧不在本页（只露出几个印文笔画，如 test/27.jpg 那种情况的黑白版），没有圆弧可拟合，仍可能被当成贴边笔迹清掉；彩色扫描时靠颜色可以保住。
- 彩色噪点若和印章颜色相同、且印章正好压在噪点里（不再是独立的圆形区域），印章的浅色部分可能被一起清掉；紧贴线条、文字的深色噪点小点会保留。
