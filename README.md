# 扫描件去黑边

清除扫描图片中的黑边、黑角、阴影条带和页边噪点，**保持原图尺寸与方向不变**，被清除的区域用周围纸张纹理修补，不留色块和分界线。

思路参考：https://blog.gtwang.org/programming/python-opencv-auto-crop-and-rotate-scanned-image-tutorial/

## 用法

```bash
uv run python pic.py 图片路径      # 处理单张
uv run python pic.py 图片目录/     # 处理目录下所有图片（不递归）
```

结果输出到 `output/`，文件名与原图相同。可选参数：`-t` 黑边灰度阈值（默认 80），`-m` 黑边向外多扩的像素（默认 4）。

## 处理思路

1. **贴边黑色区域**：灰度低于阈值且接触图片边缘的连通域即为黑边/黑角/撕裂黑块，再沿灰色过渡带生长，并按图像大小向外多扩一圈，吃掉内侧的过曝带和残余暗线。页面内部的文字不接触边缘，不受影响。
2. **页边“边框带”**：取四边中间 60% 的行/列中位数，从边缘向内找与纸张底色持续有差异的区间（过曝白带、细暗线、亮度台阶），整体交给修补，避免留下分界线。
3. **版心外噪点**：先把字符横向合并成行，确定版心；版心之外的孤立小团块（周围没有其他墨迹）和紧贴图片边缘的笔迹被清除，细长手写笔画（如“1”）和成串文字则保留。
4. **修补填充**：用 Telea 图像修补（缩小图上计算）按周围纸张填充，掩码边缘羽化混合；掩码附近的字迹先当作“未知”参与计算、最终原样保留，避免把笔画的深色抹成灰色拖影。

## 已知局限

- 假设页边最外约 4% 内没有真实内容；页边 3% 以内、版心之外的手写内容会被当作残留清除。
- 不接触图片边缘的黑色区域不会被识别为黑边。
